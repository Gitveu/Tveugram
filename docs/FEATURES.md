# FEATURES.md — Матрица функционала и черри-пиков

## Правило
При черри-пике фича сначала вытаскивается в изолированный коммит на апстриме, затем переносится. Если фича неотделима от Liquid Glass — фича отбрасывается либо глас локально вырезается.
