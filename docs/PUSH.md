# PUSH.md — Уведомления, подпись и фоновая работа на iOS 10.3.3

## 1. Контекст платформы
- **Устройство:** iPhone 5s (A7, arm64, 1 ГБ RAM).
- **ОС:** iOS 10.3.3.
- **Джейлбрейк:** h3lix (10.0–10.3.3, 64-bit).
- **Установка:** AppSync Unified, подпись через `ldid` (ad-hoc).

---

## 2. Анализ доставки уведомлений (APNs)

### 2.1 Проблема ad-hoc подписи
При установке через AppSync Unified и подписи с помощью `ldid`:
- Отсутствует валидный provisioning profile от Apple Developer Program.
- Системный сервис `apsd` (Apple Push Notification service daemon) на iOS отклоняет регистрацию токена APNs для бандлов с неподтвержденным push-entitlement (`aps-environment`), если не выполнены специальные условия.
- **Следствие:** При стандартном запуске пуши приходят только при активном приложении (через постоянное MTProto TCP-соединение).

### 2.2 Стратегии решения

#### Вариант А: Использование оригинального Bundle ID (`ph.telegra.Telegraph`)
- **Плюсы:** Все внутренние пути к App Groups, Keychain access groups и дефолты совпадают с официальным клиентом.
- **Минусы:** Нельзя установить параллельно с официальным клиентом из App Store (но на iOS 10.3.3 официальный клиент больше не обновляется и не работает, поэтому конфликт исключен).
- **APNs:** Если на устройстве ранее был сгенерирован легитимный push-токен для этого Bundle ID, `apsd` может продолжать доставлять пуши.

#### Вариант Б: Джейлбрейк-демоны и фоновая активность (Рекомендуется для iOS 10.3.3)
На джейлбрейкнутом устройстве доставка сообщений надежно обеспечивается удержанием фонового соединения:
1. **Твики многозадачности (Backgrounder / Watchdog / Dissident):**
   - Настройка `Native` или `Fast Dropout` / `Always Active` для `Telegram`.
   - Приложение поддерживает TCP-сокет к MTProto DC в спящем режиме без разрыва связи.
2. **PushFix / Сертификатные твики:**
   - Если требуется нативный APNs, используются решения для подмены push-сертификата в `apsd`.

## 3. Чек-лист проверки на живом устройстве (Вехи P1–P2)
- [ ] Регистрация `registerForRemoteNotifications()` не вызывает крэш в `AppDelegate.swift`.
- [ ] Приложение корректно обрабатывает отсутствие токена APNs (нет вечного спиннера, переход на поллинг через сокет).
- [ ] Входящие сообщения доставляются через постоянный TCP-сокет при открытом приложении.
- [ ] Проверить удержание сокета в фоне при использовании фонового твика.
