# PERF.md — Бюджеты производительности и памяти (A7 / 1 ГБ RAM)

## Бюджеты
- **RAM на холодном старте:** < 90 МБ
- **RAM в списке чатов (100 чатов):** < 150 МБ
- **RAM в активном чате с медиа (1000 сообщений):** < 220 МБ
- **Регресс памяти:** > 10% между сборками — блокирующий.
